# TopForce2

«Фронт» — прототип мобильной RTS в одном файле (`index.html`, без сборки и зависимостей).

- процедурная симметричная карта 800×1400: река / хребет / озёра / степь, лес, холмы, дороги, мосты и броды;
- камера с зумом и миникартой, поиск пути по рельефу;
- приказы, точки сбора и общая атака с фильтром по роду войск.

## Застава

`zastava.html` — вторая игра в том же стиле: оборона заставы от 20 волн (около 18 минут) с цитаделью врага на том берегу. Конвейер «казарма → оружие → ворота» с выбором рода войск, танковый завод, турели, медчасть, ДОТ у моста, мины, конвои, оружие командира с нагревом ствола, прицельный авиаудар.
