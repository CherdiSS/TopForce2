# TopForce2

«Фронт» — прототип мобильной RTS в одном файле (`index.html`, без сборки и зависимостей).

- процедурная симметричная карта 800×1400: река / хребет / озёра / степь, лес, холмы, дороги, мосты и броды;
- камера с зумом и миникартой, поиск пути по рельефу;
- приказы, точки сбора и общая атака с фильтром по роду войск.

## Застава

`zastava.html` — вторая игра в том же стиле: оборона заставы от 12 волн (около 13 минут). Конвейер «казарма → оружие → ворота», танковый завод, турели, ворота ×2, авиаудар, наведение огня командира пальцем.
